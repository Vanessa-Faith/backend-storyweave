# Reference Implementations

## 📚 What's in This Folder

This folder contains **complete, working implementations** of all the route files and utilities. Use these as **reference/examples** while you write your own code.

---

## 🎯 How to Use These Files

### **DO:**
✅ **Look at them** when you're stuck
✅ **Learn from them** - see how things are structured
✅ **Compare** your code to them
✅ **Understand** the logic and patterns

### **DON'T:**
❌ **Copy-paste** directly (you learn by writing!)
❌ **Edit** these files (they're read-only references)
❌ **Import** from these files in your code

---

## 📁 Files Available

### **auth_REFERENCE.py**
- Register user endpoint
- Login endpoint
- Get current user endpoint
- **Member 1:** Compare with your `app/routes/auth.py`

### **stories_REFERENCE.py**
- Complete Story CRUD operations
- All 6 endpoints (create, read, update, delete, list, my-stories)
- **Member 2:** Compare with your `app/routes/stories.py`

### **nodes_REFERENCE.py**
- Node creation and management
- **Tree structure algorithm** (the tricky part!)
- All 5 endpoints
- **Member 3:** Compare with your `app/routes/nodes.py`

### **auth_utils_REFERENCE.py**
- JWT token creation
- Token verification
- Get current user function
- **Member 1:** Compare with your `app/utils/auth.py`

## 💡 Recommended Workflow

1. **Try writing your code first** - Look at the TODO comments in your file
2. **Get stuck?** - Open the reference file
3. **Understand the approach** - Don't just copy!
4. **Write your own version** - In your own words
5. **Test it** - Make sure it works
6. **Compare** - How is yours different? Better? Similar?
